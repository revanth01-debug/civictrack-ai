CivicTrack AI 🚀

AI-Powered Civic Issue Management Platform

CivicTrack AI is a smart civic issue reporting and management system that enables citizens to report public issues such as garbage accumulation, potholes, water leakage, drainage problems, street light failures, and infrastructure damage. The platform uses Google Gemini AI to automatically classify issues, assess severity, assign priority levels, and suggest actions.

⚙️ Installation

Frontend Setup
cd client
npm install
npm run dev
Backend Setup
cd server
npm install
npm start
Environment Variables

Create .env file:

MONGO_URI=YOUR_MONGODB_CONNECTION_STRING
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
PORT=5000
